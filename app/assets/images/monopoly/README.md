# Huudpoly material asset

`walnut.png` is an original generated tabletop material. The board geometry, labels, tokens, dice and buildings are native Flutter drawing, driven by the server snapshot.

**Generation mode:** new image, no reference image and no editing.

**Exact prompt:**

> Use case: productivity-visual. Asset type: seamless square walnut tabletop texture for the background and thick wooden base of the approved PlayHuud classic Huud Estates game. Create a high resolution photorealistic overhead material texture filling the entire image edge to edge. Rich medium-dark walnut, warm honey highlights and brown/maroon lowlights, subtle mostly horizontal natural wood grain, satin finish, lightly worn premium board-game table. Flat even lighting, modest contrast for legible UI overlays. Uniform scale and color so it can be tiled without obvious seams. No objects, no board, no tokens, no perspective, no frame, no text, no logos, no vignette, no decorations. This is only the wood surface material.
